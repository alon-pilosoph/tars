# Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately through GitHub instead: the repository's
**Security** tab, then **Report a vulnerability**. Say what you found, how to reproduce it, and what it lets someone
do. You'll get an answer within a week.

TARS is a personal project run in one household, so there are no releases to patch: a fix lands on `main`, and the
report is credited there if you'd like.

What TARS protects, the threats it has defenses and tests for, and the ones still open are in
[docs/security.md](docs/security.md). Something already listed there as open is known, but a way to use it that the
page doesn't describe is still worth reporting.
